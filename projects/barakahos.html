Overview

About the Project

Barakahos is a mobile UI/UX design concept created for a design competition, focusing on intuitive navigation, clear visual hierarchy, and a seamless user experience.

The Challenge

Clear & Engaging UI

The challenge was to create a mobile interface that could deliver information clearly while maintaining an engaging and consistent visual experience.

The Solution

User-Centered Approach

I developed a user-centered interface with a clear navigation structure, organized content, and a visual design that makes key information easy to understand and access.
